# EUR/USD 量化交易系统 — 交易信号逻辑完整说明

> 撰写日期: 2026-07-08
> 用途: 供外部 AI / 交易员审查，寻找优化空间

---

## 一、系统概览

| 项目 | 值 |
|------|-----|
| 交易品种 | EUR/USD |
| 账户规模 | $100 / 1:100 杠杆 / 每笔 0.01 手 |
| 策略风格 | 中长线趋势跟随（非日内高频） |
| 信号频率 | 每小时检测一次（HH:05 UTC），仅 H1 收盘后 |
| 推送频率 | 每日 3 次飞书推送（07:30 / 15:00 / 22:00 北京时间） |

---

## 二、信号生成流水线（5 层）

```
        ┌──────────────┐
Layer 0 │ 基本面+日历   │ 预加载情绪分数 & 重大事件列表
        └──────┬───────┘
               ↓
        ┌──────────────┐
Layer 1 │ 大势判断      │ D1 50SMA + H4 200SMA 多周期共振
        └──────┬───────┘
               ↓  can_trade=True?
        ┌──────────────┐
Layer 2 │ 入场信号      │ H1 + M15 5EMA/15EMA 交叉 + K线形态
        └──────┬───────┘
               ↓  entry found?
        ┌──────────────┐
Layer 3 │ 风控计算      │ Widest Stop + 仓位 + R:R 验证
        └──────┬───────┘
               ↓  risk passed?
        ┌──────────────┐
Layer 4 │ 置信度评分    │ 5因子加权 → ★1~5
        └──────────────┘
```

---

## 三、Layer 0 — 基本面情绪预加载

**执行时机:** 每次信号生成最开始（即使最终观望也加载）

**数据源优先级:**
1. **LLM 分析**（优先）: `output/analysis/sentiment_YYYYMMDD.json`，由 Claude CLI 读取 37+ 条 RSS 新闻 + 已分类基本面 JSON，输出多空判断
2. **关键词打分**（降级）: 统计 `data/fundamentals/` 中长/中期新闻的多空关键词频次
3. **无数据**: 返回中性 (score=0)

**输出:**
```json
{"label": "看多/偏多/中性/偏空/看空", "score": -1.0~+1.0, "source": "Claude CLI|keywords|none"}
```

**方向判定阈值:**
- score > +0.15 → bullish
- score < -0.15 → bearish
- 其他 → neutral

## 四、Layer 1 — 大势判断（TrendAnalyzer）

### 4.1 指标

| 周期 | 指标 | 用途 |
|------|------|------|
| D1 | 50 SMA | 日线长期趋势方向 |
| H4 | 200 SMA | 4小时中期趋势方向（经典多周期共振组合） |

### 4.2 方向判定

用最近 3 根 K 线的 SMA 斜率判断 UP / DOWN / SIDEWAYS。

### 4.3 交易许可规则

| D1 50SMA | H4 200SMA | 结论 | can_trade |
|----------|-----------|------|-----------|
| UP | UP | BULLISH — 一致看多 | ✅ |
| DOWN | DOWN | BEARISH — 一致看空 | ✅ |
| UP | SIDEWAYS | BULLISH_CAUTIOUS — 谨慎做多 | ✅ |
| DOWN | SIDEWAYS | BEARISH_CAUTIOUS — 谨慎做空 | ✅ |
| UP | DOWN | CONFLICT — 趋势分歧 | ❌ 观望 |
| DOWN | UP | CONFLICT — 趋势分歧 | ❌ 观望 |
| 任意 | UNKNOWN | 数据不足 | ❌ 观望 |

**关键设计:** D1 和 H4 必须不矛盾才允许交易。BULLISH_CAUTIOUS / BEARISH_CAUTIOUS（一方横盘）允许交易但不加趋势一致性分数。

## 五、Layer 1.5 — 日历 & 星期过滤

### 5.1 周五规则
北京时间周五全天不生成新交易信号（`friday_no_trade: true`）。

### 5.2 重大事件预警
- 扫描未来 24 小时 ForexFactory 日历中的高影响事件
- 匹配关键词: FOMC, ECB, NFP, CPI, GDP, Interest Rate 等
- 命中 → `cal_warning=True`，置信度 -1

---

## 六、Layer 2 — 入场信号检测（EntryDetector）

### 6.1 指标

| 周期 | 快线 | 慢线 | 辅助 |
|------|------|------|------|
| H1 | 5 EMA | 15 EMA | ATR(14) |
| M15 | — | 15 EMA | — |

### 6.2 前置过滤（任一不通过则跳过）

| 过滤 | 条件 | 目的 |
|------|------|------|
| ATR 波动率 | 当前 H1 ATR ≥ 过去 20 根均值 × 0.8 | 过滤无量横盘 |
| 斜率动量 | H4 200SMA 斜率绝对值 ≥ 0.0003 | 过滤震荡市 |
| 追高保护 | 入场价距 H4 200SMA ≤ 1.5×ATR | 不追高 |

### 6.3 条件 A — 标准金叉/死叉（主要入场）

**做多:**
1. H1: EMA5 > EMA15
2. H1: EMA5 斜率 > 0（向上）且 EMA15 斜率 > 0（向上）
3. M15: 收盘价 ≥ EMA15 且收阳线
4. → 信号类型: `golden_cross`，基础置信度: 2

**做空:**
1. H1: EMA5 < EMA15
2. H1: EMA5 斜率 < 0（向下）且 EMA15 斜率 < 0（向下）
3. M15: 收盘价 ≤ EMA15 且收阴线
4. → 信号类型: `death_cross`，基础置信度: 2

### 6.4 条件 B — 反转入场（次要入场）

**做多（大势看多但 EMA5 < EMA15）:**
1. H1 出现多头反转形态（锤子线/吞没/启明星等）
2. H1 前 2 根 K 线连续下跌（确认回调）
3. M15 同步出现多头反转形态
4. 形态综合评分 ≥ MIN_PATTERN_SCORE（1.5，趋势因子 1.2×）
5. → 信号类型: `reversal`，基础置信度: 评分取整

**做空（大势看空但 EMA5 > EMA15）:**
1. H1 出现空头反转形态（上吊线/吞没/黄昏星等）
2. H1 前 2 根 K 线连续上涨
3. M15 同步出现空头反转形态
4. 评分 ≥ MIN_PATTERN_SCORE
5. → 信号类型: `reversal`

### 6.5 斐波那契验证

- 找 H4 级别最近波段高/低点
- 计算 38.2% / 50% / 61.8% 回调位
- 入场价距最近 fib 位 ≤ 1.0×ATR → `fib_proximity=True`（置信度 +1）

## 七、Layer 3 — 风控计算（RiskManager）

### 7.1 止损方法（Widest Stop）

取以下三者中最宽（对做多取最低，对做空取最高）：

| 方法 | 计算方式 |
|------|---------|
| ATR 止损 | 入场价 ± 1.5×ATR(14) |
| 结构止损 | 最近 swing low/high |
| EMA 止损 | 入场价 ± 1%（即 EMA15 偏离保护） |

兜底: 数据缺失时用 20pips 固定止损。

### 7.2 仓位计算

- 固定 0.01 手（$100 账户限制）
- 单笔最大亏损 = 止损 pips × 0.01 手价值

### 7.3 R:R 验证

- rr_min_ratio: 2.0（止盈:止损 ≥ 2:1）
- TP1: R:R 2.0（50% 仓位）
- TP2: R:R 3.0（50% 仓位）

## 八、Layer 4 — 综合置信度评分

### 8.1 评分公式

```
conf = 基础分(entry.confidence + 1)
     + 趋势一致性加分 (+1 if BULLISH/BEARISH, 不加 if CAUTIOUS)
     + 斐波那契回调位 (+1 if fib_proximity)
     - 重大事件预警 (-1 if cal_warning)
     ± 基本面情绪共振 (+1 if 同向, -1 if 反向)
     → clamp(1, 5)
```

### 8.2 各因子详解

| 因子 | +1 条件 | -1 条件 | 0 条件 |
|------|---------|---------|--------|
| 基础分 | entry.confidence+1 (2~6) | — | — |
| 趋势一致 | D1+H4 一致同向 | — | CAUTIOUS 模式 |
| Fib 回调 | 入场价接近 H4 50% 回调位 | — | 不接近 |
| 日历预警 | — | 未来 24h 有 FOMC/非农等 | 无大事 |
| 基本面 | LLM/关键词与趋势同向 | LLM/关键词与趋势反向 | 中性/无数据 |

### 8.3 最终输出

- ★★★★★ (5): 多重共振，高把握
- ★★★★ (4): 标准信号 + 1~2 个加分项
- ★★★ (3): 标准信号
- ★★ (2): 有扣分项，谨慎
- ★ (1): 信号存在但风险较高，供参考

## 九、错失机会追踪（OpportunityTracker）

### 9.1 机制

每天 16:00 北京时间，回看过去 24 小时所有**观望信号**：
- 检查每一条观望信号发出后的最大价格波动
- 波动 > 45pips → 记录为"错失机会"
- 提取信号时刻的市场特征（EMA 值/斜率/ATR/SMA 位置/波动方向）
- 保存到 `data/opportunities/YYYY-MM/missed_YYYYMMDD.json`

### 9.2 目的

积累特征数据 → 发现规律（如"趋势看空但 EMA5 斜率已转正时，观望信号有 X% 概率错失上涨"）→ 优化入场条件

## 十一、已知局限 & 待优化点

1. **追高保护硬编码** — `max_distance_from_h4_sma = 1.5` 在 entry.py 中硬编码，config 中无对应键
2. **斐波那契主级别硬编码** — 只看 50% 回调位，config 中 `primary_level` 键已删除（P1-6）
3. **反转形态评分阈值固定** — MIN_PATTERN_SCORE = 1.5 无配置暴露
4. **EMA 交叉只看绝对值不看出场** — 没有"EMA5 下穿 EMA15 时平多仓"的出场逻辑
5. **D1/H4 方向判定用简单斜率** — 只用最近 3 根 K 线，可能受单根大 K 线影响
6. **R:R 固定 2:1/3:1** — 未根据 ATR 或波动率动态调整
7. **单笔 0.01 手无缩放** — 不会根据置信度或账户增长调整仓位
8. **基本面 LLM 分析每天只跑一次** — 可能用过时的情绪数据
9. **没有出场/移动止损逻辑** — 只有固定 TP1/TP2
10. **错失机会特征未自动回馈到入场策略** — 目前只记录，不自动优化

OANDA API (每15min)                               LLM 情绪分数
  → data/forex/YYYYMMDD_H1.parquet                      ↓
  → TrendAnalyzer (D1 50SMA + H4 200SMA)          ┌───→ SignalGenerator
  → EntryDetector (H1+M15 5EMA/15EMA)              │        ↓
  → RiskManager (Widest Stop)                      │   FinalSignal
                                                   │        ↓
ForexFactory (每天06:00)                           │   飞书推送
  → EconomicCalendar                               │   (07:30/15:00/22:00)
  → 重大事件预警 ─────────────────────────────────┘
