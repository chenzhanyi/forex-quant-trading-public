## 一、按影响周期分类

### 🔴 长期影响（数周~数月，可能改变趋势方向）

| 事件类型 | 利多 EUR/USD | 利空 EUR/USD |
|----------|-------------|-------------|
| **央行利率决议** | ECB 加息 / 鹰派表态 | Fed 加息 / 鹰派表态 |
| **央行政策转向** | Fed 降息 / 结束紧缩 | ECB 降息 / 继续宽松 |
| **美欧贸易政策** | 美欧达成贸易协议 | 美国对欧盟加征关税 (30%) |
| **德国财政政策** | 扩大基建/国防支出 (€500B+) | 财政紧缩 / 债务刹车恢复 |
| **美元储备地位** | 去美元化加速 / 美债评级下调 | 美元避险需求回升 |
| **欧元区结构性改革** | 财政一体化 / 共同债券 | 政治分裂 / 法国意大利财政危机 |
| **地缘政治（中东）** | 停火 / 油价大跌 / 霍尔木兹恢复通航 | 冲突升级 / 油价飙升 |

### 🟡 中期影响（数天~数周，可能放大或压制波动）

| 事件类型 | 利多 EUR/USD | 利空 EUR/USD |
|----------|-------------|-------------|
| **非农就业 (NFP)** | 美国就业数据大幅低于预期 | 美国就业数据大幅超预期 |
| **CPI 通胀数据** | 美国 CPI 回落超预期 | 欧元区 CPI 反弹超预期 |
| **GDP 数据** | 欧元区 GDP 超预期 | 美国 GDP 超预期 |
| **PMI 采购经理人指数** | 欧元区 PMI 扩张 | 美国 ISM PMI 强劲 |
| **央行官员讲话** | Fed 官员鸽派 | ECB 官员鸽派 |
| **央行会议纪要** | FOMC 纪要偏鸽 | ECB 纪要偏鸽 |
| **零售销售** | 美国零售疲软 | 欧元区消费不振 |
| **贸易差额** | 欧元区顺差扩大 | 美国贸易逆差收窄 |

### 🟢 短期影响（数小时~1-2 天，日常波动）

| 事件类型 | 说明 |
|----------|------|
| **初请失业金** | 每周四公布，影响有限但可累积信号 |
| **消费者信心指数** | 密歇根大学 / 欧元区消费者信心 |
| **工业产出** | 月度数据，单独影响不大 |
| **住房数据** | 美国新屋开工/成屋销售 |
| **技术面 / 算法交易** | 关键价位突破时的加速行情 |
