# V1 策略归档 — M15 四步入场法 (2026-07)

> ⚠️ 已替换为 V2 6条件叠加法。此文档仅供历史参考。

---

## 核心逻辑

```
D1 50SMA + H4 200SMA 判大势 → M15 四步精准入场
```

### 趋势判断
- D1 50SMA 定大势方向 (UP/DOWN)
- H4 200SMA 确认中期趋势 + 斜率动量过滤

### 入场四步 (以做空为例，做多镜像)

```
1️⃣ M15 找到最近反弹最高点 (swing high) → 标记止损参考
2️⃣ EMA5/EMA15 空头排列 + 斜率向下 → 趋势确认
3️⃣ 死叉后回弹但不破前高 → retest 有效
4️⃣ 回弹处出现反转形态 (黄昏星/射击之星/阴吞阳/坚决大阴) → 入场
```

### 止损止盈
- **止损**: M15 波段极值点 + 3pips (太紧 <20pips 则升级到 H4 级别)
- **止盈 TP1**: H4 趋势级前低/前高
- **止盈 TP2**: 斐波那契 161.8% 延伸

### 过滤器
- H4 斜率动量 (slope_momentum ≥ 0.0003)
- ATR 波动率 (当前 ≥ 20均值×0.8)
- RSI 极值 (做空 <25, 做多 >75 跳过)
- 追高保护 (入场价距 H4 SMA 不超过 1.5×ATR)
- 周五不交易

### 回测表现
- 近3月 (2026-05/08): 3信号/月, 33%胜率, ~-3pips
- 震荡市打平, 趋势市待验证

### 替换原因
- 信号太少 (~3/月)
- 入场条件过于苛刻, 实盘多次因代码bug/crash漏信号
- 简化版6条件叠加法回测 79信号 72%胜率 +1105pips
